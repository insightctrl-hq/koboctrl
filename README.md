# KoboCTRL

Every kobo has a job. An envelope-budgeting app powered by InsightCTRL.

KoboCTRL is a single static page. It runs offline, keeps all data on the user's own phone, and has no accounts and no server.

## Files

- `index.html` is the whole app, with fonts embedded.
- `manifest.webmanifest` and the icon files let people install it to the home screen.

## Publishing

The site is served by GitHub Pages from the `main` branch, root folder. Push to `main` and the live site updates within a couple of minutes.

## Privacy

Personal plan and backup files never go in this repo. They are listed in `.gitignore`.
